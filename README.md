# Baronmods Website

A responsive static homepage for the Baronmods project. Built with HTML, CSS, and vanilla JavaScript; no framework or build step is required.

## Deploy to Vercel

1. In the Vercel dashboard, choose **Add New → Project**.
2. Import `cornerfood565-ctrl/Baronmods` from GitHub.
3. Choose **Other** as the framework preset.
4. Leave **Root Directory** as `./` (the repository root).
5. Leave the Build Command and Output Directory empty/default for a static site.
6. Click **Deploy**.

The homepage is `index.html`. Published download files should be added through GitHub Releases; the website links to the Releases page and does not claim that unbuilt downloads are available.

## Customize

- Edit `index.html` for text and sections.
- Edit `style.css` for the visual theme and responsive layout.
- Edit `script.js` for the mobile navigation and small interactions.
