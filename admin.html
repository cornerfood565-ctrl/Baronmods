RESTRICTED AREA / ADMIN

Mod control.

Sign in with an approved admin account to upload files and publish versions. Creating an account alone does not grant admin access.

Admin sign-in

Create your admin user in Supabase Authentication, then add its user UUID to admin_users as described in README-SUPABASE.md. There is no public sign-up form.

Publish a mod

Maximum file size is 100 MB. Only approved admins can write to Storage or publish records.

Your mod records

Unpublishing hides a mod from players. It does not delete stored files.
